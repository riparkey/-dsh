### 16.2 皮肤颗粒的实测（2026-11-11 早上，四张对照）

- 8 步 / 1024×1536 / 长提示词 → 有颗粒（`bigbutt.png`）。

- 先出图再用 `--init + denoise 0.28` 抛光 → **最糟**，把颗粒又加重一层（`polish.png`）。
- 8 步 / 精简提示词（只留「pale smooth flawless porcelain skin, airbrushed matte」）→ 最好，但仍有一点（`cl2.png`）。

结论：不是步数不够，也不是提示词没写。是这个 turbo 模型在这个尺寸下，**步数越高越要把皮肤画成真实皮肤**——该糊的地方它非要画清楚。
